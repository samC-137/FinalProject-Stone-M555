# ValutaTrade Hub

Учебный проект для виртуального валютного кошелька. В программе можно создать пользователя, вести кошельки с разными валютами и обновлять курсы из внешних источников.

## Установка

Нужны Python 3.12 или новее и `uv`.

В папке проекта выполните:

```bash
uv sync
```

## Запуск

```bash
uv run valutatrade
```

Программа откроет строку ввода. Команды можно вводить по одной. Напишите `help`, чтобы увидеть список команд, или `exit`, чтобы закрыть программу.

## Команды

- `register --username sam --password 1234` — создать пользователя.
- `login --username sam --password 1234` — войти.
- `show-portfolio --base EUR` — посмотреть кошельки и их стоимость в выбранной валюте. Если `--base` не указан, используется USD.
- `buy --currency BTC --amount 0.05` — добавить валюту в портфель.
- `sell --currency BTC --amount 0.01` — уменьшить баланс кошелька.
- `get-rate --from EUR --to USD` — посмотреть курс.
- `update-rates` — обновить курсы из обоих источников.
- `update-rates --source coingecko` — обновить только курсы криптовалют.
- `update-rates --source exchangerate` — обновить только курсы фиатных валют.
- `show-rates` — показать все курсы из локального кэша.
- `show-rates --currency EUR` — показать курсы выбранной валюты.
- `show-rates --top 2` — показать две самые дорогие криптовалюты.
- `show-rates --base EUR` — показать курсы относительно выбранной базовой валюты.

Курсы криптовалют загружаются из CoinGecko, а курсы фиатных валют — из ExchangeRate-API. Если один источник недоступен, программа всё равно сохранит данные от другого.

Покупать и продавать можно после входа. Если команда введена неверно, валюта неизвестна или на кошельке не хватает средств, программа покажет сообщение об ошибке и продолжит работу.

## Настройки

Ключи API хранятся в локальном файле `.env`. Скопируйте пример:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте свои ключи вместо пустых значений. `EXCHANGERATE_API_KEY` нужен для курсов фиатных валют. Его можно получить после регистрации бесплатного аккаунта на [сайте ExchangeRate-API](https://app.exchangerate-api.com/sign-up). `COINGECKO_API_KEY` необязателен: без него приложение использует публичный API CoinGecko, а с ключом — Demo API. Ключ CoinGecko можно создать в [кабинете API](https://www.coingecko.com/en/api/pricing).

При запуске приложение само читает `.env`. Этот файл исключён из Git, поэтому ключи не попадут в GitHub. Добавляйте секреты только в `.env`, а `.env.example` оставляйте без настоящих ключей. Срок актуальности курсов и базовая валюта заданы в `pyproject.toml` в разделе `[tool.valutatrade]`.

## Данные

Пользователи, портфели, текущие курсы и история курсов хранятся в JSON-файлах папки `data`.

- `data/users.json` — учётные записи.
- `data/portfolios.json` — кошельки пользователей.
- `data/rates.json` — последние курсы валют.
- `data/exchange_rates.json` — история обновлений курсов.

Курс можно использовать, пока он не старше срока в `pyproject.toml`: для криптовалют это `rates_ttl_seconds` (300 секунд), для фиатных валют — `fiat_rates_ttl_seconds` (24 часа). Сроки отличаются, потому что источники обновляют данные с разной частотой. Если курс устарел, программа предложит обновить его командой `update-rates`. Эта команда запрашивает курсы у источников и сохраняет доступные данные в локальный кэш.

## Структура проекта

- `valutatrade_hub/core` — модели и основные действия с пользователями и портфелями.
- `valutatrade_hub/infra` — настройки и работа с JSON-файлами.
- `valutatrade_hub/parser_service` — загрузка и сохранение курсов.
- `valutatrade_hub/cli` — команды для работы в терминале.
- `logs` — журналы действий и обновления курсов.

## Логи

При запуске программы создаётся папка `logs`. В `actions.log` сохраняются регистрации, входы и сделки, а в `parser.log` — работа с источниками курсов. Файлы автоматически ротируются при достижении 1 МБ. Пароли в лог не записываются.
