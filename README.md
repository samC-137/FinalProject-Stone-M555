# ValutaTrade Hub

Учебный проект для виртуального валютного кошелька. В программе можно будет создавать пользователя, вести кошельки с разными валютами и смотреть курсы.

## Установка

Нужны Python 3.12 или новее и `uv`.

В папке проекта выполните:

```bash
uv sync
```

Команда установит зависимости и подготовит окружение проекта.

## Запуск

Запустить программу можно так:

```bash
uv run valutatrade
```

Или напрямую:

```bash
uv run python main.py
```

Пока подготовлена основа проекта. Команды для пользователей и работы с курсами будут добавляться по этапам.

## Настройки

Для получения курсов через ExchangeRate-API позже понадобится переменная окружения `EXCHANGERATE_API_KEY`. Ключ не нужно записывать в исходный код или добавлять в Git. До подключения сервиса курсов эта переменная не требуется.

## Где хранятся данные

Учебные данные будут храниться в папке `data`: пользователи, портфели, актуальные курсы и история курсов. Файлы с данными добавлены в проект как пустые заготовки.
