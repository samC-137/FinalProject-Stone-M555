# ValutaTrade Hub

Учебный проект для виртуального валютного кошелька. В программе можно создать пользователя, вести кошельки с разными валютами и обновлять курсы из внешних источников.

## Установка

Нужны Python 3.12 или новее и `uv`.

В папке проекта выполните:

```bash
uv sync
```

## Запуск

```bash
uv run valutatrade
```

Программа откроет строку ввода. Команды можно вводить по одной. Напишите `help`, чтобы увидеть список команд, или `exit`, чтобы закрыть программу.

## Команды

- `register --username alice --password 1234` — создать пользователя.
- `login --username alice --password 1234` — войти.
- `show-portfolio` — посмотреть кошельки и их стоимость в USD. Другую базовую валюту можно указать через `--base`.
- `buy --currency BTC --amount 0.05` — добавить валюту в портфель.
- `sell --currency BTC --amount 0.01` — уменьшить баланс кошелька.
- `get-rate --from EUR --to USD` — посмотреть курс.
- `update-rates` — обновить курсы.
- `show-rates --top 2` — показать две самые дорогие криптовалюты.

Курсы криптовалют загружаются из CoinGecko, а курсы фиатных валют — из ExchangeRate-API. Если один источник недоступен, программа всё равно сохранит данные от другого.

## Настройки

Срок актуальности курсов и базовая валюта заданы в `pyproject.toml` в разделе `[tool.valutatrade]`. Для курсов фиатных валют задайте переменную окружения `EXCHANGERATE_API_KEY`. Без неё можно обновить курсы криптовалют. Ключ не нужно записывать в исходный код или добавлять в Git.

В macOS или Linux перед запуском можно задать ключ так:

```bash
export EXCHANGERATE_API_KEY="ваш_ключ"
```

## Данные

Пользователи, портфели, текущие курсы и история курсов хранятся в JSON-файлах папки `data`.

## Логи

При запуске программы создаётся папка `logs`. В `actions.log` сохраняются регистрации, входы и сделки, а в `parser.log` — работа с источниками курсов. Файлы автоматически ротируются при достижении 1 МБ. Пароли в лог не записываются.
